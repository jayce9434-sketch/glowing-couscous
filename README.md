# Hivefall

Hivefall is a single-player insect colony strategy sandbox built as a static web game.

## Play locally
Open `index.html` in a browser, or serve the folder with any static web server.

## GitHub Pages
1. Create a GitHub repository.
2. Upload every file in this zip directly to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select your main branch and `/ (root)`.
5. Save. GitHub will publish the game as a website.

## Included gameplay
- Ants, termites, bees, flies, and spiders with different strategic bonuses
- Nation-scale territory map with visible borders and capitals
- Neutral expansion and resource regions
- Real wars with territorial conquest and combat losses
- Diplomacy: trade, non-aggression pacts, alliances, peace treaties, declarations of war
- AI colonies that expand, fight, trade, ally, and remember diplomatic actions
- Physical nest builder with nurseries, food chambers, barracks, walls, storage, tunnels, clinics, and watch posts
- Structures directly affect population growth, economy, defense, army capacity, and recovery
- Colony history / chronicle
- Local browser save/load
- Pause, 1x, 2x, 4x simulation speeds
- Touch controls for iPad/iPhone plus mouse support for desktop
- No external libraries or assets required
